Desktop Key Bindings

App-focused bindings work in the Lumiverse window. Global bindings also work in the background and must be enabled individually. No shortcuts are enabled by default.

F13–F24 work on their own or with modifiers. Other keys require Control, Alt/Option or Command/Super. Shortcuts use physical key positions.

Choose keys manually

Use this when the OS or an existing global shortcut intercepts the keys you want to record.

Open and sign in to the integrated browser to bind application and Spindle commands. Those bindings belong to that instance and account. Disabled extensions and unavailable commands cannot trigger.
