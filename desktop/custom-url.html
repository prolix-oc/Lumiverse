Uses this folder’s .env, account, and data. Requires an installed Bun runtime.

HTTPS required

LAN and private IP addresses also require HTTPS. Both Desktop and the integrated browser need a trusted certificate matching the hostname or IP address. Only localhost development can use HTTP.

Add this origin under the server’s Settings → Operator → Trusted Hostnames, then restart the server. Desktop authorization opens in your system browser and is separate from the integrated browser’s login.
